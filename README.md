## 広告ギャラリー（2026-10-30）

- `gallery.html`：15枚の公開用画像一覧。クリックで拡大し、App Storeへ移動可能。
- `index.html`：代表作5枚を6秒ごとに自動切替。手動送り・停止、ホバー／フォーカス／非表示時の停止、動きを抑える設定に対応。
- `ads/`：WebP表示用と軽量サムネイル。原本PNG・制作記録はローカル制作フォルダーに保持。内部分析・プロンプト・個人情報は公開しない。
- `gallery.json`：公開用の画像情報。追加時は画像、一覧HTML、件数、必要ならトップ選抜を同期し、ALTと公開可能な表記を確認する。
- テスト：`node --test tests/*.cjs`、`node --check gallery.js`。ブラウザーで拡大・閉じる・自動切替・手動送り・停止を確認。

### 最新順の自動掲載

`gallery.json` が表示順・トップ選択の正本。新しい画像のWebPとサムネイルを追加し、台帳へ登録すればHTMLを手で選び直す必要はない。`date` は制作日（YYYY-MM-DD）、`order` は同日内の登録順（大きいほど新しい、登録時に最大値+1）。一覧は日付降順・登録順降順。トップは同じ順で `top: false` を除外した先頭5枚。`kalimpad-choose-your-sound` はトップ除外、一覧には残す。画像を読み込む際に同じ台帳から両ページを更新する。通信失敗時は保存済みHTMLを表示する。自動再生は初期ON（6秒）、停止操作や操作中・非表示時は停止。動きを抑える設定ではスライド移動をアニメーションさせない。
